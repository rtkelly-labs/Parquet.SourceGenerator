# Legacy/modern emitted API parity allowlist (#493, docs/guides/legacy-support.md § Enforcement).
#
# BackendParityGateTests runs every golden model through both generators, renders each emitted
# surface with the .api.txt renderer, normalises the namespace and the extension class name
# (<Model>ParquetLegacyExtensions -> <Model>ParquetExtensions), and diffs the lines. Every
# difference must be listed here, and every entry here must still be a difference:
#
#   - A difference that is not listed fails the gate. Close the gap; do not add a line here
#     without a section that names the reason and the tracking issue.
#   - An entry that no longer differs fails the gate. Remove it in the change that closes the gap.
#     The list can only shrink.
#   - A [permanent] entry is a recorded owner decision that the member is modern-only. It also fails
#     if the legacy backend starts emitting the member: absent, never present-and-throwing.
#
# Grammar:
#   [temporary #N] reason          starts a section of gaps to close, tracked by issue #N
#   [permanent #N] reason          starts a section of modern-only members by decision
#   modern-only <Model>: <line>    the modern backend emits <line> and the legacy one does not
#   legacy-only <Model>: <line>    the legacy backend emits <line> and the modern one does not
#   modern-only <Model>: *         the legacy backend emits nothing for <Model> at all
#
# Lines are the normalised .api.txt lines, so a failing run prints each unlisted difference in
# exactly this form.

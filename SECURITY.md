# Security Policy

## Supported Versions

Nothing has been published yet, so there is no supported release. Once a version ships, only the
latest published version will receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in **Parquet.SourceGenerator**, please report it
privately rather than opening a public issue.

### How to Report
- Use [GitHub Private Vulnerability Reporting](https://github.com/rtkelly-labs/Parquet.SourceGenerator/security/advisories/new)
  on this repository, or email the maintainer directly at <94ryan.kelly@gmail.com>.
- Include steps to reproduce, sample C# code, or a minimal reproduction repository if possible.

### What to Expect

This is a personal project maintained in spare time, so please treat any response time as
best-effort rather than a commitment. Reports will be acknowledged and triaged as soon as
practical, and you will be kept informed of progress on anything confirmed.

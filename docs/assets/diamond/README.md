# Minimalist Diamond Parquet Mark — Candidate 3 Direction

This directory preserves and documents the **Minimalist Diamond Parquet Mark**, synthesized using the modern deterministic vectorization, RDP polygon simplification, and drift calibration pipeline from `shared_utilities.image_drift`.

---

## 1. Concept & Heritage

The mark revisits the core aesthetic foundations of the original project concept while eliminating nonsensical visual clutter (such as artificial circuit badges, socket rings, and etching):

- **Interlocking Parquet Planks**: A bold 45-degree rotated diamond (rhombus) card composed of interlocking cedar and warm oak parquet wood planks, directly paying homage to the Apache Parquet columnar storage format.
- **Git Branching Lineage**: A clean 3-way git commit branching tree carved into the wood seams, symbolizing source generation lineage (from root schema to emitted column-reading code).
- **Vibrant Glowing Nodes & Git Triad**: 3 distinct semantic branch streams — Electric Cyan trunk (`#00F5FF`), Radiant Neon Violet left feature branch (`#C084FC`), and Solar Amber right feature branch (`#F59E0B`) blending with the warm oak parquet tones, on a rich dark navy-charcoal background (`#161D2C`).

## 3. Production Asset Manifest

High-precision Lanczos downsampling produces artifact-free cuts across all standard resolutions:

* **`parquet-diamond.svg`**: Resolution-independent vector master (138 KB CAD polygon SVG, accessible `viewBox="0 0 1024 1024"`).
* **`parquet-diamond-1000x1000.png`**: High-resolution 1000×1000 master raster.
* **`parquet-diamond-avatar-500x500.png`**: 500×500 profile avatar for GitHub repositories and organizations.
* **`parquet-diamond-avatar-180x180.png`**: 180×180 web and mobile icon cut.
* **`apple-touch-icon.png`**: 180×180 iOS/macOS web clip touch icon.
* **`favicon.ico`**: Multi-resolution Windows/browser icon bundle (16×16, 32×32, 48×48).
* **`favicon-{16,32,48,512}.png`**: Standalone web favicons for responsive browser tab scaling.
* **`parquet-diamond-reference.png`**: 1024×1024 ground truth raster baseline.
* **`parquet-diamond-diagnostic-sheet.png`**: 3-panel comparative diagnostic sheet `[Reference | Rendered SVG | Diff Heatmap]`.

# Generator Configuration

By default, the source generator emits serialization and deserialization code supporting flat primitives as well as compound types (nested structs and lists).

## Enforcing Flat-Only Schemas

If your project requires strict flat-only schemas or compatibility with consumers that cannot process nested structures, you can configure the generator to reject compound members at compile time (emitting diagnostic `PARQ006`):

```xml
<PropertyGroup>
  <ParquetGeneratorFlatOnly>true</ParquetGeneratorFlatOnly>
</PropertyGroup>
```

When `<ParquetGeneratorFlatOnly>true</ParquetGeneratorFlatOnly>` is set, any attempt to annotate a model containing nested structs or collections will be reported as an unsupported type error at build time.

## Emitted File Headers

Every generated source artifact records its configuration and generator version in its header comment:

```csharp
// <auto-generated />
// ParquetGeneratorFlatOnly: False
// ParquetGeneratorVersion: 0.1.0
#nullable enable
```

This ensures generated outputs can be audited directly from source without reflection.
